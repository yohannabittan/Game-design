# Playtest: Checkpoint v6 (release v1.4)

- **Date:** 2026-10-01 (from the designer's chat notes, expanded by the orchestrator)
- **Build:** cache checkpoint-v7 (dev), release v1.4
- **Context:** phone. Sessions, minutes, offline: not stated.

## Delight test

- "A good concept and it works, but it's missing fun, difficulty, umph, storytelling."

## Findings

| | Comment |
| --- | --- |
| Difficulty | Too easy: bags need more occlusion (items hidden under others). |
| Variety | More kinds of items, in more colours. |
| Legibility | Some shapes read wrongly: the lighter did not look like a lighter; the scissors looked odd. |
| Story | Missing: there is no traveller, only bags. |
| Umph | Missing (juice, stakes). |

## Wishes (the designer's words, condensed)

1. Show the person walking through the metal detector while their bags go down the belt on the left.
2. The people are almost a misdirect (attention split between the person and the bag), but a traveller with a really bad item (a gun) gets jumped by SWAT.
3. Letting a really bad item (a gun) through is an instant loss.
4. More occlusion; more item kinds and colours; redrawn lighter and scissors.

## Decision input

- Evolve: PRD v0.2 (traveller lane, severity tiers with the gun as instant loss, SWAT moment, occlusion and item set, readable silhouettes, juice), built feel-first per the Launch learnings.
