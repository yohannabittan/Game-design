# Recoil style anchor

Prepend verbatim to every image prompt for this game (PRD v0.6 D):

"80s movie-studio backlot at night, chunky flat vector with thick dark outlines, dark soundstages lit by neon pink and teal, painted-flat sets, one orange accent for the player, strong readable silhouettes, no text, no photorealism."

Before v0.6 the anchor was: "Chunky flat vector game art with thick dark outlines, warm gunmetal greys with one orange accent, slightly exaggerated proportions, side view, strong readable silhouette, no text, no photorealism, no gradients except a single soft highlight." Gun silhouettes keep that proportion and outline rule.
