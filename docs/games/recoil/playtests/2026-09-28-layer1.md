# Playtest: Recoil layer 1 (cache recoil-v2)

- **Date:** 2026-09-28
- **Context:** phone, landscape, Accuracy and Speed 1 to 3.

## Delight test

- Wanted one more go: yes. "Recoil was good, a lot of the elements are there. Overall good potential."

## Findings and decisions

1. **Too easy: the range finder tells you exactly when to shoot.** With still or straight-approaching targets, reading the barrel line is enough for a bullseye every time. Decision: targets that move between aim and shot (weave, dodge, hordes, skeet arcs), and guns whose accuracy shortens the range finder, so the line is a hint, not an answer. PRD v0.2.
2. **Guns as profiles.** Damage, fire rate, accuracy, plus the existing kick, recovery and magazine. Accuracy sets the range finder length. Damage needs targets with hit points. Decision: v0.2 defines the gun profile and ships two guns; the unlock table follows in the progression layer.
3. **Challenges scale on motion, size, speed and quantity.** Decision: ladders take those as data per level.
4. **New challenge types.** Skeet: targets launched in arcs from below. Boss: weak points to hit in order, then a hardened core needing several hits. Decision: both in v0.2, one level each.
