# Playtest: Ink v0.1 (ten stencils, no juice)

- **Date:** 2026-09-28
- **Build:** cache ink-v5
- **Context:** phone, from the Pages URL.
- **Sessions:** a full run through the ten stencils.

## Delight test

- Wanted one more go: yes. "This was fun, I enjoyed it."
- Why: the final boss was a real challenge; the snake and the key have personality.

## Findings and decisions

1. **Personality comes from story, not complexity.** The snake and key read as pieces; the gem, heart and star read as geometry. Decision: the art layer gives the early stencils a story element each (a banner across the heart, a swirl in the star, a facet line in the gem). Noted for layer 5.
2. **Two experiences, wrong way round.** Filling a tattoo is precise edge work plus fast repetitive filling. Today the middle is free and all the skill is at the edge. The designer proposes a needle whose ink width follows speed: slow lays more, fast lays less. Decision: build it as an experiment behind a menu toggle (classic versus dynamic needle) with the range in tuning, so both can be played back to back. Recorded as PRD v0.2.
3. **The final boss timer is right.** A real challenge, cleared. No change.

## Decision input

- Evolve. Layer 3 juice (in progress), then the dynamic needle experiment (v0.2), then the art pass with story elements.
