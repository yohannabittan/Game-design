# Arena step: "What's new" in the game (locked 2026-11-14)

**The designer:** "A new update landed, what was in this one? I think we need a changelog in the game so I can see what to test."

## What the player gets

- **On the menu, a small plaque with the build number** (for example "v72 · NEW"). It is always there, at least 44 px to touch, and takes nothing away from Play.
- **Tapping it opens a card: "What's new".** The newest build is on top with its number and two to five short lines, each written as something to try ("Throw a knife into a gap: it now hits for 12."). Older builds follow, the last five in all, reached by swiping or paging. A tap outside or on Close returns to the menu.
- **The words live in one plain list** (`games/arena/src/notes.js`: build number, date, lines). The orchestrator adds an entry at every landing; nobody else needs to touch code for it.
- It is the same in the friends' release: the list simply ends at the build the release was cut from.

## Seed entries (newest first)

- **v73, 14 Nov:** Take a spear: it is as long as his now. / Let a foe step in close and push: your hand slides up the shaft and the point still lands. / The trident does the same.

- **v70, 14 Nov:** Throw an overhead in a hurry: lift and chop, no pause at the top. / A slash with a big back-swing is now an overhead: say if that catches you out. / In the training yard, copy the ghost thumb: it moves at a speed you can match.
- **v69, 14 Nov:** Each blow looks like itself: a jab's streak, a slash's smear, an overhead's chop; sparks on plate, blood on skin.

## Acceptance

1. At 874x402 and 667x375 the plaque is on the menu, shows the top entry's build number, has a 44 px touch area, and covers nothing that was tappable before.
2. The card shows the newest entry first; five entries can be reached; no line is clipped at 667x375; Close and a tap outside both return to the menu.
3. The build number shown equals the number in `CACHE_VERSION`. `tools/docs-check.mjs` fails when `notes.js` has no entry for the shipped `CACHE_VERSION` (the same way it already fails for a missing changelog line), so the list cannot fall behind.
4. No change to the save, the fight or the first run. `npm run check arena` and the smoke test pass; no replay hash moves.
5. `RULES.md` gains a line on the plaque and card; `RECIPES.md` gains "at a landing: add the entry to `notes.js`"; `docs/team.md`'s orchestrator card gains the same line.

## Open, simplest option taken

- **No "unread" dot and no memory of what you have seen:** that would change the save. The build number on the plaque is the signal.
- **Arena only** for now. The mini games can take the same card later if the designer wants it.
- **Drawn on the canvas** like everything else (rule 4); the engine is not touched.

## The designer will judge it

By a still of the menu with the plaque and a still of the open card, and by using it at the next update.
