## What went stale or got in the way

- **Arena's code map** described v36 while the game reached v66: 513 of 553 pointers were wrong.
- **The orchestrator's handoff** said `arena-v48` and listed bugs fixed long ago.
- **Builders' check helpers** were rewritten each build, in a temporary folder.
- **Landing copied whole files,** which is what kept Arena to one builder at a time.
- **What the designer had to say twice:** frames didn't show motion problems (the double arms, twice; then the slash and overhead feel). That led to sketch before build, and GIFs.

## What we changed (this retro's three)

1. **A generated code index, a lookup command and recipes** (`tools/codemap.mjs`, `RECIPES.md`), kept fresh by the landing tool and the smoke test.
2. **Landing merges three ways,** and Arena is to be split into core and feature modules (ADR-0024), so two builders can work at once.
3. **Sketch before build:** a still, a GIF or a touchable page before any look-or-feel step.

Also `tools/docs-check.mjs` (first named "doctor", renamed the same day: it is a script, not an agent), which on its first run caught a folder named in `CLAUDE.md` before it existed.

## What we removed

1. **Arena's hand-written CODEMAP table** (60 lines of prose with line numbers), replaced by a pointer to the generated index.
2. **`tools/codemap-check.mjs` for Arena:** the generated index and the recipe check do its job. It stays for the other games' hand-written maps until they switch.

## Model changes, and one guard to try without

- The orchestrator moved to a stronger model on 2026-11-14.
- **The guard to try without:** "never two builders on one game". After the split, run the blow effects (Step 26) and Trials (Step 27) side by side.
- **What brings it back:** a landing conflict the merge can't settle cleanly, or a bug that only shows with both builds in.
